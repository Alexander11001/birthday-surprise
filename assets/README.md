# Файлы для сайта

Положите сюда три файла:

| Файл | Описание |
|------|----------|
| `mystery.jpg` | Картинка «до клика» (загадка, силуэт, знак вопроса — что угодно) |
| `reveal.png` | Фото-сюрприз по клику |
| `song.mp3` | Песня-сюрприз (уже в репо) |
| `reveal.png` | Фото-сюрприз (уже в репо) |

Без этих файлов сайт откроется, но картинки и музыка не заработают.

**Авторские права:** mp3 нужно положить самостоятельно (купленная копия, лицензия или короткий мем-клип для личного поздравления).
